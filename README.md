# A Little Something for Ananya ❤️

A small, personal website created to express a heartfelt apology, gratitude, and appreciation for a friend.

## ✨ Features

- Vintage and dreamy aesthetic
- Three interactive pages
- Personalised introduction for Ananya
- Heartfelt apology message
- Thank-you message and emotional ending
- Background music integration using YouTube
- Smooth page transitions and animations
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- YouTube IFrame Player API

## 🌷 Purpose

Sometimes, a simple text message isn't enough to express what you feel. This little project was created to convey a sincere apology and appreciation through a personalised experience.

## 💌 A Final Note

Made with sincerity, care, and a little hope.

**All the best for your future. Hope we will meet soon.** ❤️
